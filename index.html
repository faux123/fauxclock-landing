Network

TCP congestion control, queueing disciplines, and buffer tuning.

Haptic Tuning

Vision / Color

FauxClock Pro

Advanced performance features for power users.

SuperFDO

System-wide uclamp floor with workload classification and thermal gating. Goes beyond static tweaks with adaptive, sensor-driven scheduling.

Per-App Uclamp

Per-TID sched_setattr with in-app GUI. Pin minimum performance floors to individual threads without editing JSON configs.

Thread Control

Per-TID cluster pinning (sched_setaffinity), I/O priority (ionice), and nice values (renice). Full thread placement control through a real GUI.

Activate with a license key at Settings → FauxClock Pro

Community Benchmarks

Opt-in anonymous telemetry aggregates battery drain, thermal headroom, and throttle events across devices. See how your kernel config stacks up against the community.
